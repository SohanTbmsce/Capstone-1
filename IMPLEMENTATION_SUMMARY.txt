RESILIENCE4J CONFIGURATION
=============================================================================

Rate Limiter (LoginRateLimiter):
  Component: Resilience4j RateLimiter
  Key Strategy: Per-username+IP combination
  Limit: 5 requests per minute
  Timeout: 0 (fail immediately, no waiting)
  Storage: In-memory ConcurrentHashMap
  Independent: Each key has its own limiter instance

Circuit Breaker (LoginCircuitBreaker):
  Component: Resilience4j CircuitBreaker
  State Machine: CLOSED -> OPEN -> HALF_OPEN -> CLOSED
  Failure Detection:
    - Records: ExternalServiceException (system failures)
    - Ignores: InvalidCredentialsException (business logic)
  
  Thresholds:
    - Failure Rate: 50% (circuit opens when ≥50% of calls fail)
    - Minimum Calls: 5 (need at least 5 calls before evaluating)
    - Sliding Window: 10 calls (track last 10)
  
  Timing:
    - Wait Duration Open: 30 seconds
    - Permitted Calls Half-Open: 3 (test 3 calls while recovering)
  
  When OPEN:
    - Fails fast without calling external service
    - Returns 503 immediately
    - Prevents cascading failures

Exception Handling (GlobalExceptionHandler):
  400 Bad Request: Validation errors (missing username/password)
  401 Unauthorized: InvalidCredentialsException (wrong password)
  429 Too Many Requests: RateLimitExceededException (too many attempts)
  503 Service Unavailable: ExternalServiceException (system failure)
  500 Internal Server Error: Unexpected exceptions

CRITICAL ARCHITECTURAL DISTINCTIONS
=============================================================================

401 Unauthorized (Invalid Credentials):
  What: Wrong password or unknown username
  Cause: User provided incorrect credentials
  Circuit Breaker Impact: NOT counted as failure
  Config: recordExceptions does NOT include InvalidCredentialsException
  Response: 401 HTTP status
  Behavior: Rate limit consumed, but circuit remains unaffected
  Purpose: Prevent false circuit opening due to user errors

503 Service Unavailable (External Service Failure):
  What: External auth service down, unreachable, or timeout
  Cause: System/infrastructure failure
  Circuit Breaker Impact: IS counted as failure
  Config: recordExceptions includes ExternalServiceException
  Response: 503 HTTP status
  Behavior: Circuit opens after ≥50% failures
  Purpose: Protect system from cascading failures
  Test: Use username="serviceDown" to simulate

Rate Limiting Enforcement:
  Runs: BEFORE credential verification (first check)
  Purpose: Prevent brute force attacks at entry
  Per-Key: Each username+IP combination has independent limit
  Rejection: Returns 429 immediately without calling external service
  Reason: Why waste resources on rate-limited requests?

Step 2: Implement authenticate() Method
  public LoginResponse authenticate(String username, String password,
                                   String clientIp) throws Exception {
      // 1. Rate limit check (automatic, transparent)
      loginRateLimiter.checkRateLimit(username, clientIp);
      
      // 2. External validation (with circuit breaker protection)
      externalLoginService.validateExternalLogin(username, password);
      
      // 3. Your responsibility: Generate JWT
      String jwt = generateJwt(username);
      
      // 4. Your responsibility: Store token in memory
      tokenRepository.store(username, jwt);
      
      // 5. Return response
      return new LoginResponse(jwt, "Login successful");
  }

Step 3: Create AuthController
  @RestController
  @RequestMapping("/auth")
  public class AuthController {
      private final AuthService authService;
      
      @PostMapping("/login")
      public ResponseEntity<LoginResponse> login(
              @Valid @RequestBody LoginRequest request,
              HttpServletRequest httpRequest) throws Exception {
          
          String clientIp = httpRequest.getRemoteAddr();
          
          LoginResponse response = authService.authenticate(
              request.getUsername(),
              request.getPassword(),
              clientIp
          );
          
          return ResponseEntity.ok(response);
      }
  }
